\# AI Career Mentor



AI Career Mentor is an intelligent web-based platform that helps students and job seekers identify suitable career paths based on their interests, skills, academic background, and goals.



\## Technologies

\- React.js

\- Node.js

\- Express.js

\- MySQL

\- OpenAI API

\- Git \& GitHub



\## Features

\- User Authentication

\- Career Assessment

\- AI Career Recommendations

\- Learning Roadmaps

\- Certification Suggestions

\- Dashboard
